# Motrix - 懒猫云应用

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![LazyCat Cloud](https://img.shields.io/badge/LazyCat-Cloud-blue)](https://lazycat.cloud)

简洁易用、功能丰富的现代下载管理器，支持 HTTP、BT、磁力链等协议。

## 功能特性

- ⚡ **多协议支持**: HTTP、BitTorrent、Magnet、Metalink 等
- 🎨 **清爽界面**: 简洁的 Web 管理界面
- 📂 **多实例**: 支持创建多个下载实例，独立管理
- 🔔 **下载通知**: 实时查看下载进度
- 🌐 **跨平台**: 基于 Web 的远程管理

## 安装说明

通过懒猫应用商店安装，搜索 "Motrix" 即可。

## 配置参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 下载目录 | 当前实例的下载文件夹名称 | Motrix Downloads |
